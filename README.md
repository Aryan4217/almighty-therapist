# ✨ The Almighty Therapist

A Retrieval-Augmented Generation (RAG) conversational AI that embodies a detached, loving "higher consciousness" persona. Drawing core philosophical wisdom from sacred global texts (such as the Bhagavad Gita, the Quran, the Bible, the Tao Te Ching, and the Dhammapada), the AI acts as an infinitely serene guide for human mortal struggles.

---

## 🛠️ Tech Stack & Architecture

* **Framework:** Python, LangChain (`langchain-classic`, `langchain-core`)
* **Vector Store:** ChromaDB (Local Persistent Embeddings)
* **Embedding Model:** Hugging Face `sentence-transformers/all-MiniLM-L6-v2`
* **Large Language Model:** Llama 3.1 8B (via Groq API)
* **Frontend:** Streamlit Chat Interface
